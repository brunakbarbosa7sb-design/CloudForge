# CloudForge V12 — APK Android

Versão limpa, sem GitHub e Tailscale na interface.

## Gerar o APK pelo celular

1. Crie um repositório vazio no GitHub.
2. Envie **todo o conteúdo deste pacote** para a raiz do repositório.
3. Abra a aba **Actions**.
4. Abra **Gerar APK CloudForge** e toque em **Run workflow**.
5. Quando finalizar, abra a execução e baixe o artefato **CloudForge-APK**.
6. Dentro do ZIP do artefato estará `app-debug.apk`.

O APK abre o CloudForge em tela cheia/paisagem e funciona como demonstração.
FiveM/GTA V reais ainda exigirão futuramente um host Windows com GPU.
